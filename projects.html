Guitar Hero

Simple version of the video game Guitar Hero built using an FPGA, a VGA monitor, SD-Audio, and System Verilog

Built with a group of 3 others. I led group meetings and the planning and implementation of game logic, memory, and graphics. The audio and controller mapping were also planned and implemented from scratch.

SKILLS: building and testing circuits, writing graphics to a VGA, debugging hardware description languages, implementing game logic, memory mapping, bit manipulation, syncing audio and visuals to a clock, using a PLL, teamwork, leadership

PARTS
  breadboard and common circuit components
  FPGA
  VGA and SD adapters
  VGA monitor
  amplifier
  external speaker
  original Guitar Hero controller that was modded to fit with a breadboard
