Guitar Hero

A playable Guitar Hero clone built from scratch in System Verilog, driving real-time graphics and audio on an FPGA.

Led a team of 4 in designing and building a fully functional Guitar Hero clone on an FPGA, from architecture through final integration. Directed project planning and owned the core game logic, memory system, and real-time VGA graphics pipeline, while also engineering the audio playback and controller input mapping from scratch.

SKILLS: building and testing circuits, writing graphics to a VGA, debugging hardware description languages, implementing game logic, memory mapping, bit manipulation, syncing audio and visuals to a clock, using a PLL, teamwork, and leadership.

PARTS:

  • Breadboard and common circuit components
  • FPGA
  • VGA and SD adapters
  • VGA monitor
  • Amplifier
  • External speaker
  • Original Guitar Hero controller that was modded to fit with a breadboard

Modular Synth

A custom hardware synthesizer built for real-time wavefolding, frequency/amplitude modulation, and low-/high-pass filtering.

Co-designed and built a modular hardware synthesizer from the ground up with a team of 4. Owned the signal pipeline end-to-end: implemented UART parsing of touch data from a Sensel Morph pad, converted it to MIDI, and cleaned the stream for real-time digital signal processing. Also designed the system's hardware diagram, supported DSP/DAC debugging, and coordinated team meetings and check-ins to keep development on track.

SKILLS: C programming, circuit building, Raspberry Pi (config, code deployment), DSP, DACs

PARTS:

  • Sensel Morph touch pad
  • Raspberry Pi Zero W
  • STM32
  • OLED I2C display
  • speaker

Mechanical Keyboard

A fully custom 65% mechanical keyboard, hand-built and tuned from a hot-swap PCB to the final keycap set.

Designed and assembled a custom 65% mechanical keyboard from individual components, researching and selecting parts to balance sound, feel, and aesthetics. Tested and validated the hot-swap PCB, then lubricated, installed, and fine-tuned each switch by hand. Biggest takeaway: hands-on iteration taught me more about the build process than research alone ever could.

SKILLS: using/ testing PCBs, troubleshooting, and inserting/ replacing switches for a hot-swap PCB.

PARTS:

  • Barebones kit: Bakenko65
  • Switches: HMX Butter Linears
  • Keycaps: Keith Haring Inspired Keycap Set
  • Switch Lubricant: HONKID Keyboard Switch Lube GPL 205G0
